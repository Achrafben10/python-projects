# Personal Productivity Manager

A Python project that I created to manage my tasks and track my habits.

The program also saves my data in a JSON file, so my tasks and habits
are still available when I run the program again.

## Features

- Add tasks
- Show tasks
- Complete tasks
- Delete tasks
- Add habits
- Track completed habits
- Show productivity summary
- Calculate task completion percentage
- Save data automatically
- Load saved data when the program starts

## Data Storage

The program uses a JSON file to store:

- Tasks
- Habits
- Task completion status
- Habit completion count

This means the data does not disappear when the program is closed.
