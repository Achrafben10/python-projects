# Mystery Island

A simple text adventure game that I created to practice Python conditions, loops, functions, and user choices.

## Features

- Multiple story paths
- Three different doors
- Different choices and outcomes
- Winning and losing situations
- Replay option
- Case-insensitive choices
- Interactive text-based gameplay

## What I Learned

Through this project, I practiced:

- Functions
- `while` loops
- `if / elif / else`
- Nested conditions
- `input()`
- `lower()`
- `break`
- Variables
- Organizing a program into functions
- Creating different outcomes based on user choices

## How It Works

The player wakes up on a mysterious island and must choose between three doors:

- Red door
- Blue door
- Yellow door

Each door leads to a different part of the story.

The player's decisions determine whether they survive, discover the secret of the island, or lose the game.

## Technologies

- Python

## My Goal

I created this project to improve my understanding of conditional logic and learn how different user choices can control the flow of a program.
