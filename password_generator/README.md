# Strong Password Generator

A Python project I created to practice generating strong and random passwords based on user requirements.

## Features

- Choose the password length
- Choose the number of uppercase letters
- Choose the number of lowercase letters
- Choose the number of numbers
- Choose the number of symbols
- Generate a random password
- Mix all characters randomly

## Example

The user can choose:

Password length: 12  
Uppercase letters: 2  
Lowercase letters: 4  
Numbers: 3  
Symbols: 3

The program then generates a random password based on these requirements.
