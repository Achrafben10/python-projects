# Gym Management System

A simple Python project that I created to practice programming
by building a small gym member management system.

## Features

- Add a new member
- Show all members
- Search for a member by name or ID
- Set a member as Active or Inactive
- Simple main menu
- Clear the terminal screen
- Automatic return to the main menu

## Member Information

Each member has:

- First name
- Last name
- Member ID
- Active / Inactive status
