# Library Management System

A Python project that I created to practice managing and organizing
book information using lists, dictionaries, functions, loops, and conditions.

## Features

- Add new books
- Show current books
- Create a book wishlist
- Show wishlist books
- Move purchased books from the wishlist to the library
- Donate books
- Show donated books
- Search for books by title or author
- Simple menu system

## How It Works

The program organizes books into three different lists:

- Current books
- Wishlist
- Donated books

When I buy a book from my wishlist, the program removes it from the
wishlist and adds it to my current books.

When I donate a book, the program removes it from my current books
and moves it to the donated books list.
