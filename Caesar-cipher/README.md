# Caesar Cipher

A simple Python project that I created to practice encryption and decryption using the Caesar Cipher.

## Features

- Encrypt messages
- Decrypt messages
- Choose the shift number
- Keep spaces and symbols unchanged
- Simple terminal interface

## What I Learned

Through this project, I practiced:

- Functions
- `for` loops
- Conditions
- Strings
- `isalpha()`
- `isupper()`
- `ord()`
- `chr()`
- Modulo `%`
- User input
- Basic encryption logic

## Technologies

- Python

## Example

The user enters a message and a shift number.

The program then shifts the letters and creates an encrypted message.

The same program can also decrypt the message by reversing the shift.

## My Goal

I created this project to understand how a simple encryption algorithm works and to improve my Python programming skills.
