# Rock Paper Scissors

A simple Python game where I play Rock Paper Scissors against the computer.

## Features

- Play against the computer
- Computer chooses randomly
- Learn the game rules
- Rock, Paper and Scissors hand drawings
- Score tracking
- Play multiple rounds
- Exit whenever you want
- Input validation

## What I Learned

Through this project, I practiced:

- Functions
- `while` loops
- `if / elif / else`
- Lists
- `random.choice()`
- `input()`
- `lower()`
- `break`
- `continue`
- Variables and score tracking

## How It Works

The player chooses:

1. Rock
2. Paper
3. Scissors

The computer then makes a random choice.

The program compares both choices and determines the winner of the round.

## Technologies

- Python
- Random module

I created this project to practice Python programming and learn how to organize a small interactive game using functions and loops.
